# Chord Wheel

The circle of fifths you can hear. Pick any major or minor key on the wheel, hear its diatonic
chords as synthesized triads, and build + play back your own chord progressions.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/chord-wheel/

Pure client-side HTML/CSS/JS. All sound is generated live with the Web Audio API - no samples,
no backend, no tracking.
